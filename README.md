## DCF Method

**FCFF = EBIT x (1 - Tax Rate) + D&A - Capex - Change in NWC**

**Terminal Value = FY32E FCFF x (1 + g) / (WACC - g)**

**Enterprise Value = PV of Explicit FCFF + PV of Terminal Value**

**Equity Value = Enterprise Value + Cash/Investments - Debt-like Liabilities**
